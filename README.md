# KINGDOM Shape & Resonance Lab 01 v0.1

**What can a shape sing? · Phase 0 · Static · Synthetic · Draft**

This zero-dependency Node.js producer generates one closed machine snapshot, eight accessible SVG diagrams, and three tiny deterministic PCM16 WAV sonifications. It keeps physical models, numerical approximations, sonification, perception, and cultural interpretation separate; every exhibit includes assumptions, units, a claim, non-claims, and a falsifier.

The producer performs no network request. The artifacts contain no microphone, upload, recording, participant, personal data, runtime synthesis, autoplay, tracking, acoustic-pressure prediction, health/healing claim, consciousness claim, sacred-geometry claim, universal-aesthetic claim, or authority.

## Commands

Node.js 20 or later is required. No package install or network access is needed.

```sh
npm test
npm run validate
npm run build
npm run build:check
npm run check
npm run overview
```

`build` atomically replaces only the declared inventory under `public/`. `build:check` proves all generated bytes match. Schema generation is a separate maintainer-only command and is not part of a normal build.

The eight SVGs and three WAVs use the nested immutable family `https://thekingdom.dev/labs/shape-resonance/{assets|audio}/...`. WAV access is through reader-activated same-origin links only; the browser may download, open, or play a selected file. There is no embedded audio control and no page-load audio request.
