# Repository instructions

These instructions apply to the whole repository.

## Contract

Preserve `KINGDOM Shape & Resonance Lab 01 v0.1` as a deterministic, zero-dependency, offline, static, synthetic Phase-0 producer. It publishes mathematical models and declared sonifications only. It does not observe a physical object, predict radiated acoustic pressure, assess a listener, or establish an aesthetic, cultural, therapeutic, spiritual, governmental, scientific, or decision authority.

The required chain stays typed and visibly separated:

`geometry + topology + metric + boundary + material -> operator -> eigenmodes -> excitation/damping -> structural motion + mechanical energy -> acoustic coupling OR declared sonification -> audio -> bounded musical/perceptual/cultural interpretation`.

Never collapse physical resonance into musical harmony; mechanical energy into loudness, affect, value, or a metaphorical “energy”; or mathematical regularity into universality. Never add microphones, uploads, live data, participants, personal records, WebAudio synthesis, autoplay, producer-time network access, page-load audio requests, external audio requests, tracking, health/healing claims, consciousness claims, sacred-geometry claims, or execution/decision authority. The public site may perform one same-origin GET for a WAV only after a reader explicitly activates its audio control.

## Frozen inputs and outputs

Inputs are exact, bounded JSON at `data/config.json` and `data/sources.json`. Source records are URL-only orientation: no source body, body receipt, exact-text inference, currency inference, endorsement, licence, reuse permission, or authority.

The build may atomically replace only the declared fixed inventory in `public/`. Schema generation may atomically replace only `schemas/v0.1/public-snapshot.schema.json`. Do not introduce clocks, randomness, locale-sensitive formatting, network calls, dependencies, or undeclared generated files.

## Editing and verification

- Use Node.js built-ins only; keep runtime and development dependencies absent.
- Keep the sole public schema on Draft 2020-12. Every object is closed and every property is required.
- Preserve fatal UTF-8 decoding, decoded duplicate-key rejection, prototype-key rejection, safe integers, structural bounds, symlink rejection, null-prototype canonicalisation, exact input/schema/output receipts, fixed output paths, and atomic write/rename behavior.
- Every exhibit retains its claim, non-claims, falsifier, assumptions, typed conversions, units, accessible text equivalent, and quantisation/numerical caveats.
- WAV files are finite, deterministic PCM fixtures labelled `DECLARED-SONIFICATION`; they are not acoustic predictions and never autoplay.
- Do not initialise Git, publish, tag, freeze, release, deploy, or message external systems until explicit maintainer authorization and independent review.

Before presenting a release candidate, run:

```sh
npm test
npm run validate
npm run build
npm run build:check
npm run check
npm run overview
```

Then repeat the build and prove every generated byte is unchanged; verify there are no symlinks, undeclared files, dependencies, or changes outside this repository.
